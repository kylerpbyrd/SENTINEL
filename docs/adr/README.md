# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the Sentinel project.

## ADR Format

Each ADR follows this template:

```
# ADR-NNN: Title

## Problem
## Context
## Options Considered
## Decision
## Tradeoffs
## Consequences
## Future Revisions
```
